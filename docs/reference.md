## Special forms

### def

`(def name value)`

Defines a global binding.

```lisp
(def pi 3.14159)   → 3.14159
```

### defn

`(defn name (params) body…)`

Defines a function. A parameter list may end with `. rest` to collect the remaining arguments.

```lisp
(defn square (n) (* n n))
(square 7)   → 49
```

### defun

`(defun name (params) body…)`

The Common Lisp spelling of defn — the same form.

```lisp
(defun square (n) (* n n))
```

### fn

`(fn (params) body…) → function`

An anonymous function.

```lisp
(map (fn (n) (* n 2)) '(1 2 3))   → (2 4 6)
```

### lambda

`(lambda (params) body…) → function`

The Common Lisp spelling of fn — the same form.

```lisp
(map (lambda (n) (* n 2)) '(1 2 3))   → (2 4 6)
```

### defmacro

`(defmacro name (params) body…)`

Defines a macro; rest parameters and quasiquote are allowed.

```lisp
(defmacro when (test . body)
  `(if ,test (do ,@body) nil))
```

### let

`(let (a 1 b 2) body…)`

Local bindings, given as one flat list. Each may refer to the ones before it.

```lisp
(let (a 2 b (* a 3)) (+ a b))   → 8
```

### set!

`(set! name value)`

Reassigns an existing binding. It is an error if the name is unbound.

```lisp
(def n 1)
(set! n (+ n 1))   → 2
```

### if

`(if test then else)`

Two-way branch. Only false and nil are falsy — 0, "" and () are all true.

```lisp
(if (> 3 2) "bigger" "smaller")   → "bigger"
```

### cond

`(cond test result …)`

Flat multi-way branch: pairs of test and result, first match wins.

```lisp
(cond (< n 0) "neg"
      (= n 0) "zero"
      true    "pos")
```

### and

`(and a b …)`

Short-circuiting conjunction — returns the first falsy value, or the last one.

```lisp
(and 1 2 3)   → 3
```

### or

`(or a b …)`

Short-circuiting disjunction — returns the first truthy value.

```lisp
(or nil false 7)   → 7
```

### do

`(do e…)`

Evaluates its forms in order and returns the last.

```lisp
(do (println "hi") 42)   → 42
```

### begin

`(begin e…)`

The Scheme spelling of do — the same form.

```lisp
(begin 1 2 3)   → 3
```

### for-each

`(for-each var list body…)`

Runs the body once per element, for its effects. Returns nil.

```lisp
(for-each x '(1 2 3) (println x))
```

### loop

`(loop (a 0 b 1) body…)`

A tail-recursive loop with its own bindings; `recur` jumps back with new values.

```lisp
(loop (i 0 acc 0)
  (if (> i 4) acc (recur (+ i 1) (+ acc i))))   → 10
```

### recur

`(recur v…)`

Jumps back to the enclosing loop with a new set of values. Tail position only.

```lisp
(recur (+ i 1) (* acc i))
```

### quote

`(quote x)  ·  'x`

Returns its argument unevaluated.

```lisp
'(1 2 3)   → (1 2 3)
```

### quasiquote

`(quasiquote x)  ·  `x`

A template: `,` unquotes one value, `,@` splices a list in.

```lisp
(def xs '(2 3))
`(1 ,@xs 4)   → (1 2 3 4)
```

### unquote

`(unquote x)  ·  ,x`

Inside a quasiquote, evaluates x and drops the value in.

### unquote-splicing

`(unquote-splicing x)  ·  ,@x`

Inside a quasiquote, evaluates x and splices the list in.

## Arithmetic

### +

`(+ a b …) → number`

Adds every argument.

```lisp
(+ 1 2 3)   → 6
```

### -

`(- a b …) → number`

Subtracts the rest from the first. `(- 5)` is 5 — write -5 for a negative literal.

```lisp
(- 10 3 2)   → 5
```

### *

`(* a b …) → number`

Multiplies every argument.

```lisp
(* 2 3 4)   → 24
```

### /

`(/ a b …) → number`

Divides left to right. Dividing by zero is an error.

```lisp
(/ 100 5 2)   → 10
```

### mod

`(mod a b) → number`

The remainder of a divided by b.

```lisp
(mod 7 3)   → 1
```

### abs

`(abs n) → number`

Absolute value.

```lisp
(abs -4)   → 4
```

### min

`(min a b …) → number`

The smallest number. Lists are searched too, skipping nil and text — so (min B1:B9) reads a range.

```lisp
(min 3 '(1 nil 2))   → 1
```

### max

`(max a b …) → number`

The largest number. Lists are searched too, skipping nil and text.

```lisp
(max 3 '(1 nil 7))   → 7
```

### sum

`(sum a b …) → number`

Adds the numbers, looking inside lists and skipping nil and text — what a sheet's (sum B1:B9) needs. Nothing to add is 0.

```lisp
(sum 1 '(2 nil "x" 3))   → 6
```

### avg

`(avg a b …) → number`

The mean of the numbers, looking inside lists and skipping nil and text. An error when there are none.

```lisp
(avg '(2 4 nil))   → 3
```

### floor

`(floor n) → number`

Rounds down.

```lisp
(floor 2.7)   → 2
```

### ceil

`(ceil n) → number`

Rounds up.

```lisp
(ceil 2.1)   → 3
```

### round

`(round n) → number`

Rounds to the nearest whole number, halves away from zero.

```lisp
(round 2.5)   → 3
```

### pow

`(pow base exp) → number`

Raises base to exp.

```lisp
(pow 2 10)   → 1024
```

### expt

`(expt base exp) → number`

The Common Lisp spelling of pow — the same function.

```lisp
(expt 2 10)   → 1024
```

## Comparison and logic

### =

`(= a b …) → bool`

Structural equality: lists and dicts compare by content, functions never compare equal.

```lisp
(= '(1 2) '(1 2))   → true
```

### !=

`(!= a b) → bool`

The negation of =.

```lisp
(!= 1 2)   → true
```

### <

`(< a b …) → bool`

True when the arguments are in strictly ascending order.

```lisp
(< 1 2 3)   → true
```

### >

`(> a b …) → bool`

True when the arguments are in strictly descending order.

```lisp
(> 3 2 1)   → true
```

### <=

`(<= a b …) → bool`

Ascending order, ties allowed.

```lisp
(<= 1 1 2)   → true
```

### >=

`(>= a b …) → bool`

Descending order, ties allowed.

```lisp
(>= 2 1 1)   → true
```

### not

`(not x) → bool`

Logical negation. Only false and nil are falsy — 0, "" and () are all true.

```lisp
(not 0)   → false
(not nil)   → true
```

## Strings

### str

`(str a b …) → string`

Concatenates anything, converting as needed.

```lisp
(str "x=" 42)   → "x=42"
```

### str-len

`(str-len s) → number`

Length in characters.

```lisp
(str-len "hello")   → 5
```

### str-upper

`(str-upper s) → string`

Upper-cases a string.

```lisp
(str-upper "hi")   → "HI"
```

### str-lower

`(str-lower s) → string`

Lower-cases a string.

```lisp
(str-lower "Hi")   → "hi"
```

### str-trim

`(str-trim s) → string`

Drops leading and trailing whitespace.

```lisp
(str-trim "  hi  ")   → "hi"
```

### str-split

`(str-split s sep) → list`

Splits on a separator.

```lisp
(str-split "a,b,c" ",")   → ("a" "b" "c")
```

### str-join

`(str-join sep parts) → string`

Joins a list with a separator. Either argument order is accepted.

```lisp
(str-join "-" '("a" "b"))   → "a-b"
```

### str-contains

`(str-contains s needle) → bool`

Is needle anywhere in s?

```lisp
(str-contains "hello" "ell")   → true
```

### str-matches

`(str-matches s pattern) → bool`

Regular-expression test.

```lisp
(str-matches "a1" "^[a-z][0-9]$")   → true
```

### str-replace

`(str-replace s target repl) → string`

Replaces every occurrence of target.

```lisp
(str-replace "a-b-c" "-" "+")   → "a+b+c"
```

### substr

`(substr s start end) → string`

A slice by character index: 0-based, end-exclusive.

```lisp
(substr "hello" 1 3)   → "el"
```

### str-starts-with

`(str-starts-with s prefix) → bool`

Does s begin with prefix?

```lisp
(str-starts-with "hello" "he")   → true
```

### str-ends-with

`(str-ends-with s suffix) → bool`

Does s end with suffix?

```lisp
(str-ends-with "hello" "lo")   → true
```

## Lists

### list

`(list a b …) → list`

Builds a list. `[a b]` is shorthand for the same thing.

```lisp
(list 1 2 3)   → (1 2 3)
```

### cons

`(cons x lst) → list`

Prepends one element.

```lisp
(cons 1 '(2 3))   → (1 2 3)
```

### head

`(head lst)`

The first element, or nil when the list is empty.

```lisp
(head '(1 2 3))   → 1
```

### car

`(car lst)`

The Lisp spelling of head — the same function.

```lisp
(car '(1 2 3))   → 1
```

### tail

`(tail lst) → list`

Everything after the first element.

```lisp
(tail '(1 2 3))   → (2 3)
```

### cdr

`(cdr lst) → list`

The Lisp spelling of tail — the same function.

```lisp
(cdr '(1 2 3))   → (2 3)
```

### nth

`(nth lst i)`

The element at index i, 0-based; nil past the end.

```lisp
(nth '(1 2 3) 1)   → 2
```

### length

`(length lst) → number`

How many elements the list has.

```lisp
(length '(1 2 3))   → 3
```

### append

`(append a b) → list`

Concatenates two lists.

```lisp
(append '(1 2) '(3))   → (1 2 3)
```

### reverse

`(reverse lst) → list`

The list back to front.

```lisp
(reverse '(1 2 3))   → (3 2 1)
```

### range

`(range from to step) → list`

A list of numbers, end-exclusive. With one argument it starts at 0; step defaults to 1.

```lisp
(range 1 5)   → (1 2 3 4)
(range 3)     → (0 1 2)
```

### map

`(map f lst) → list`

Applies f to every element.

```lisp
(map (fn (n) (* n n)) '(1 2 3))   → (1 4 9)
```

### filter

`(filter pred lst) → list`

Keeps the elements pred says yes to.

```lisp
(filter even? '(1 2 3 4))   → (2 4)
```

### reduce

`(reduce f init lst)`

Folds the list left to right, f taking (accumulator element).

```lisp
(reduce + 0 '(1 2 3))   → 6
```

### sort-by

`(sort-by keyfn lst) → list`

A stable ascending sort by a numeric key.

```lisp
(sort-by str-len '("ccc" "a" "bb"))   → ("a" "bb" "ccc")
```

### zip

`(zip a b) → list`

Pairs two lists up, stopping at the shorter one.

```lisp
(zip '(1 2) '("a" "b"))   → ((1 "a") (2 "b"))
```

### empty?

`(empty? lst) → bool`

Is the list empty?

```lisp
(empty? '())   → true
```

## Dicts

### dict

`(dict :k v …) → dict`

Builds a dict. `{:k v}` is the literal syntax; keys keep their insertion order.

```lisp
(dict :a 1 :b 2)   → {:a 1 :b 2}
```

### dict-get

`(dict-get d :k)`

The value at a key, or nil.

```lisp
(dict-get {:a 1} :a)   → 1
```

### dict-set

`(dict-set d :k v) → dict`

A new dict with the key set — the original is untouched.

```lisp
(dict-set {:a 1} :b 2)   → {:a 1 :b 2}
```

### dict-keys

`(dict-keys d) → list`

The keys, in insertion order.

```lisp
(dict-keys {:a 1 :b 2})   → ("a" "b")
```

### dict-values

`(dict-values d) → list`

The values, in insertion order.

```lisp
(dict-values {:a 1 :b 2})   → (1 2)
```

### dict-has

`(dict-has d :k) → bool`

Is the key present?

```lisp
(dict-has {:a 1} :a)   → true
```

### dict-merge

`(dict-merge a b) → dict`

Merges two dicts; keys from b win.

```lisp
(dict-merge {:a 1} {:a 9 :b 2})   → {:a 9 :b 2}
```

## Dates

### now

`(now) → number`

The current time, in epoch seconds.

```lisp
(date-format (now) "HH:mm")   → "09:41"
```

### today

`(today) → number`

Midnight today, in epoch seconds.

```lisp
(date-format (today) "yyyy-MM-dd")   → "2026-09-11"
```

### date-format

`(date-format d pattern) → string`

Formats an epoch number or a "YYYY-MM-DD" string. Pattern defaults to "yyyy-MM-dd HH:mm".

```lisp
(date-format (today) "EEEE")   → "Friday"
```

### date-add

`(date-add date n unit) → string`

Shifts a "YYYY-MM-DD" date by n :days, :weeks or :months.

```lisp
(date-add "2026-09-11" 3 :days)   → "2026-09-14"
```

### date-diff

`(date-diff a b) → number`

Whole days from a to b, both "YYYY-MM-DD" strings.

```lisp
(date-diff "2026-09-11" "2026-09-14")   → 3
```

## Evaluation, JSON and the network

### print

`(print x …) → nil`

Prints its arguments with no trailing newline. Captured by the host, not written to a terminal.

```lisp
(print "a" "b")
```

### println

`(println x …) → nil`

Prints its arguments and a newline.

```lisp
(println "total:" 42)
```

### eval

`(eval form)`

Evaluates a value as code — the other half of `parse`.

```lisp
(eval (parse "(+ 1 2)"))   → 3
```

### apply

`(apply f args)`

Calls f with a list of arguments.

```lisp
(apply + '(1 2 3))   → 6
```

### json-parse

`(json-parse s)`

Reads a JSON string into dicts, lists and scalars.

```lisp
(json-parse "{\"a\":1}")   → {:a 1}
```

### json-stringify

`(json-stringify v) → string`

Writes a value as JSON.

```lisp
(json-stringify {:a 1})   → "{\"a\":1}"
```

### http-get

`(http-get url) → string`

A synchronous GET. With `http-post`, the only network access in the language.

```lisp
(json-parse (http-get "https://example.com/api"))
```

### http-post

`(http-post url body) → string`

A synchronous POST.

```lisp
(http-post "https://example.com/api" "{}")
```

## Finding your way around

### functions

`(functions filter) → nil`

Lists every function, macro and special form in scope; the filter keeps the names containing it.

```lisp
(functions)          ; everything
(functions "date")   ; just the date ones
```

### source

`(source name) → nil`

Shows a definition: the source and comments for EELisp code, the manual entry for a builtin.

```lisp
(source map)
(source zzalinhar)
```

### function-list

`(function-list filter) → list`

What (functions) lists, as data: one dict per name with name, kind, sig and summary.

```lisp
(map (fn (r) (dict-get r "name")) (function-list "str-j"))   → ("str-join")
```

## Bytes and bits

### band

`(band a b …) → number`

Bitwise AND of the integers.

```lisp
(band 0xf0 0x3c)   ; → 48
```

### bor

`(bor a b …) → number`

Bitwise OR of the integers.

```lisp
(bor 0xf0 0x0f)   ; → 255
```

### bxor

`(bxor a b …) → number`

Bitwise exclusive OR of the integers.

```lisp
(bxor 0xff 0x0f)   ; → 240
```

### bnot

`(bnot a) → number`

Bitwise NOT (two's complement: -a - 1). Mask it for a byte: (band (bnot a) 0xff).

```lisp
(band (bnot 0x0f) 0xff)   ; → 240
```

### shl

`(shl a n) → number`

a shifted left n bits. An error past 2^53, where numbers stop being exact.

```lisp
(shl 1 8)   ; → 256
```

### shr

`(shr a n) → number`

a shifted right n bits, keeping the sign.

```lisp
(shr 0x4000 8)   ; → 64
```

### make-bytes

`(make-bytes n [fill]) → bytes`

A mutable buffer of n bytes, all 0 (or fill). Up to 16 MB.

```lisp
(make-bytes 65536)
```

### bytes-len

`(bytes-len b) → number`

The size of a buffer.

```lisp
(bytes-len (make-bytes 8))   ; → 8
```

### bget

`(bget b i) → number`

The byte at index i, 0 to 255.

```lisp
(bget (list->bytes '(7 8 9)) 1)   ; → 8
```

### bset

`(bset b i v) → number`

Stores v & 0xff at index i, in place, and returns the byte stored.

```lisp
(bset ram 0x4000 0xff)
```

### bfill

`(bfill b start len v) → nil`

Sets len bytes from start to v.

```lisp
(bfill ram 0x4000 6144 0)
```

### bcopy

`(bcopy dst di src si len) → nil`

Copies len bytes from src at si to dst at di. dst and src may be the same buffer, overlapping.

```lisp
(bcopy ram 0x8000 prog 0 (bytes-len prog))
```

### list->bytes

`(list->bytes lst) → bytes`

A buffer holding a list of integers, each taken & 0xff.

```lisp
(list->bytes '(0x3e 0x02 0x76))
```

### bytes->list

`(bytes->list b) → list`

A buffer's bytes as a list of numbers.

```lisp
(bytes->list (make-bytes 3 1))   ; → (1 1 1)
```

### bytes->base64

`(bytes->base64 b [start len]) → string`

A buffer, or a run of it, as standard base64 — how bytes cross to a host.

```lisp
(bytes->base64 ram 0x4000 6912)
```

### base64->bytes

`(base64->bytes s) → bytes`

A new buffer from standard base64. An error if s isn't base64.

```lisp
(bytes->list (base64->bytes "AQID"))   ; → (1 2 3)
```

## Sheets

### sheet-new

`(sheet-new name) → string`

Creates an empty sheet file and returns its path. An error if the file exists.

```lisp
(sheet-new "Budget")
```

### sheet-open

`(sheet-open name) → dict`

The whole sheet for a host to draw: `{:path :version :cells ((row col input value error fmt) …) :widths ((col width) …) :heights ((row height) …)}`, rows and columns from 0. Runs no formula — values are the ones stored.

```lisp
(sheet-open "Budget")
```

### sheet-bytes

`(sheet-bytes name) → string`

A sheet's .eesheet file, as base64 — how a host that reads only text carries a sheet (Export as HTML).

```lisp
(str-len (sheet-bytes "Budget"))
```

### sheet-from-bytes

`(sheet-from-bytes name base64) → string`

A new sheet file made from base64 bytes (what sheet-bytes gives) — refuses bytes that aren't a sheet, and an existing file.

```lisp
(sheet-from-bytes "Copy" (sheet-bytes "Budget"))
```

### sheet-close

`(sheet-close name) → nil`

Closes the file. Do it before renaming or deleting one.

```lisp
(sheet-close "Budget")
```

### sheet-get

`(sheet-get name cell)`

One cell's value. A cell whose formula failed is an error.

```lisp
(sheet-get "Budget" "C3")   → 1650
```

### sheet-rows

`(sheet-rows name area) → list`

An area's values as a list of rows.

```lisp
(sheet-rows "Budget" "A1:B2")   → (("rent" 1200) ("food" 450))
```

### sheet-set

`(sheet-set name cell input) → list`

Types into a cell — `1200`, `rent`, `'42` for text, `=(sum B1:B2)` for a formula — recalculates what depends on it and saves. A number written as one is read as one: `50%` is 0.5 shown as a percentage, `$1,200` and `1.200,50` are money and a thousand two hundred. `2026-09-16` is a date; other spellings of one stay text. Given a list of rows, types a whole block from that corner, as a paste would. Returns the changed cells as `(row col input value error fmt)`.

```lisp
(sheet-set "Budget" "B2" "450")
(sheet-set "Budget" "C1" '(("=(sum B1:B2)") ("=(/ C1 12)")))
```

### sheet-put

`(sheet-put name cell data) → list`

Writes a block with its top-left corner at cell: a list of rows, one flat row, or a result set — a header row, then its records. Values stay values: text that would read as a number or formula is kept as text.

```lisp
(sheet-put "Report" "A1" (query contacts :order "name"))
```

### sheet-copy

`(sheet-copy name area) → list`

What was typed into an area, as rows of text — the other half of sheet-paste.

```lisp
(sheet-copy "Budget" "B1:B3")   → (("1200") ("450") ("=(sum B1:B2)"))
```

### sheet-paste

`(sheet-paste name cell rows from) → list`

Types rows of input from a cell. Given `from` — where they were copied — every formula's references move by the distance travelled, so a pasted total adds up its new neighbours. Without it the text is typed exactly, which is what a paste from another program needs.

```lisp
(sheet-paste "Budget" "C1" (sheet-copy "Budget" "B1:B3") "B1")
```

### sheet-fill

`(sheet-fill name source target) → list`

Repeats the source over the target area, each copy's references shifted by where it lands — filling a column of totals down. The source's own cells are left alone.

```lisp
(sheet-fill "Budget" "C1" "C2:C12")
```

### sheet-recalc

`(sheet-recalc name) → list`

Reruns every formula — for ones that read the database or the clock, and for another sheet that wasn't open at the time, none of which are tracked.

```lisp
(sheet-recalc "Budget")
```

### sheet-format

`(sheet-format name area fmt) → list`

Merges a format into every cell of an area — a key set to nil is removed, and a nil format clears it. Given rows of formats instead, sets each cell's exactly from the area's corner. The keys are the host's: :num, :dp, :cur, :date, :bold, :italic, :align, :wrap, :bg, :fg, :border.

```lisp
(sheet-format "Budget" "B1:B9" {:num "currency" :dp 2})
```

### sheet-col-width

`(sheet-col-width name col width) → nil`

A column's width, or nil for the default.

```lisp
(sheet-col-width "Budget" "A" 160)
```

### sheet-row-height

`(sheet-row-height name row height) → nil`

A row's height, or nil for the default. Rows are numbered from 1.

```lisp
(sheet-row-height "Budget" 3 48)
```

### sheet-insert-rows

`(sheet-insert-rows name row n) → dict`

Inserts n rows (default 1) before a row numbered from 1. Formulas are rewritten to follow their cells.

```lisp
(sheet-insert-rows "Budget" 3)
```

### sheet-delete-rows

`(sheet-delete-rows name row n) → dict`

Deletes n rows from a row numbered from 1. A formula that read a deleted cell reads #REF!.

```lisp
(sheet-delete-rows "Budget" 3 2)
```

### sheet-insert-cols

`(sheet-insert-cols name col n) → dict`

Inserts n columns before a column.

```lisp

```

### sheet-delete-cols

`(sheet-delete-cols name col n) → dict`

Deletes n columns from a column.

```lisp

```

### sheet-version

`(sheet-version name) → number`

A counter that moves on every write — how a host notices a sheet changed.

```lisp

```

Is n exactly zero?

```lisp
(defn zero? (n) (= n 0))
```

```lisp
(defn pos?  (n) (> n 0))
```

### neg?

`(neg? n)` · function

Is n less than zero?

```lisp
(defn neg?  (n) (< n 0))
```

### first

`(first lst)` · function

The first element of a list.

```lisp
(defn first  (lst) (head lst))
```

`(second lst)` · function

The second element of a list.

```lisp
(defn second (lst) (nth lst 1))
```

`(third lst)` · function

The third element of a list.

### last

`(last lst)` · function

The last element of a list.

```lisp
(defn last   (lst)
  (if (empty? (tail lst))
    (head lst)
    (last (tail lst))))
```

### take

`(take n lst)` · function

The first n elements.  (take 2 '(1 2 3)) → (1 2)

```lisp
(defn take (n lst)
  (if (or (= n 0) (empty? lst))
    (list)
    (cons (head lst) (take (- n 1) (tail lst)))))
```

### drop

`(drop n lst)` · function

Everything after the first n elements.  (drop 2 '(1 2 3)) → (3)

```lisp
(defn drop (n lst)
  (if (or (= n 0) (empty? lst))
    lst
    (drop (- n 1) (tail lst))))
```

### count

`(count lst)` · function

How many elements a list has — the same as length.

```lisp
(defn count (lst) (length lst))
```

### some?

`(some? pred lst)` · function

Does any element satisfy pred?

```lisp
(defn some? (pred lst)
  (if (empty? lst)
    false
    (if (pred (head lst)) true (some? pred (tail lst)))))
```

### every?

`(every? pred lst)` · function

Do all elements satisfy pred?

```lisp
(defn every? (pred lst)
  (if (empty? lst)
    true
    (if (pred (head lst)) (every? pred (tail lst)) false)))
```

### compose

`(compose f g)` · function

Combines two functions: (compose f g) is the function x → (f (g x)).

```lisp
(defn compose (f g) (fn (x) (f (g x))))
```

### when

`(when test . body)` · macro

Run the body only when test is true; otherwise nil.

```lisp
(defmacro when (test . body)
  `(if ,test (do ,@body) nil))
```

### unless

`(unless test . body)` · macro

Run the body only when test is false; otherwise nil.

```lisp
(defmacro unless (test . body)
  `(if ,test nil (do ,@body)))
```
